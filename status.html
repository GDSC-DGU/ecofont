4. 결정이 필요한 사항 (Open Items)

⚠️ 표시된 항목은 후속 작업의 선행 조건. 노란 배경은 일반 대기, 빨간 배경은 우선 결정 필요.
Open-1 · 잉크 절약률 산출 방법 우선 결정
우제 API가 응답 metrics.mean_ink_saving으로 자체 산출(기존 backend metrics_calculator.py는 제거됨). 산출 기준(면적/커버리지 등) 정의를 우제와 확인 필요.
담당: 이소은 + 이우제 · 데드라인: Week 3 진입 전 (B-3 시작 전)
Open-2 · CO2 환산 계수 우선 결정
잉크량 → CO2(g) 환산. 우제 응답엔 mean_ink_saving만 있고 CO2 없음 → 프론트 표시에 CO2가 필요한지 먼저 결정, 필요 시 환산 공식(논문 근거).
담당: 이소은 · 데드라인: Week 3 진입 전 (B-4 시작 전)
✅ 변환 결과 계약 불일치 (variants) — 해소 resolved
우제 Cherokee API가 candidates[20](각 ttf_url·preview_url·metrics)을 반환 → 프론트 FontList 다중 결과 UX와 정렬. 기존 백엔드 단일 결과 계약은 폐기(backend 통째 대체).
담당: 소은·우제·정선 · 2026-06-24 해소

MVP는 Cherokee(ocr_lang=chr) 전용으로 확정. 우제 생성 API가 후보별 mean_ocr_score 산출에 사용.
담당: 류동현 · 2026-06-24 확정
