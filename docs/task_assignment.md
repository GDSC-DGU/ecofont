# Task Assignment: Eco-Font Project

---

## 역할 분담

| 담당자 | 역할 | 근거 |
|--------|------|------|
| 이소은 | Backend + Infrastructure | 백엔드 경험 다수, 클라우드·인프라 관심 |
| 이정선 | Frontend (주) + AI (Vertex AI 연동) | 프론트 경험 다수, AI 관심 — API 레벨 AI 작업으로 진입 |
| 이우제 | AI 총괄 (최적화 엔진) | AI·생성모델 전문 |
| 류동현 | Frontend (지원) + AI (OCR 가독성 검증 파이프라인) | 프론트 경험 다수, 생성모델 관심 — OCR 검증 파트 담당 |
