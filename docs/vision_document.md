# Vision Document: Eco-Font Project

## 1. Executive Summary

**Eco-Font Project**는 사용자가 업로드한 모든 **.ttf 폰트 파일을 AI 기술을 통해 잉크 절약형 에코폰트로 자동 변환해 주는 웹 기반 플랫폼**입니다. 기존 에코폰트가 특정 언어에 국한되어 전 세계 다양한 언어와 브랜드 폰트에 적용하기 어려웠던 문제를 **가독성-잉크절약 최적화 알고리즘**으로 해결합니다. 특히 높은 인쇄 비용으로 인해 학습 자료를 출력조차 하지 못하는 **교육 소외 계층**을 핵심 수혜 대상으로 삼으며, 가독성을 유지하면서도 인쇄 시 **최소 20%의 잉크 절감**을 달성하여 경제적 장벽 없이 누구나 인쇄 기반 학습에 접근할 수 있는 환경을 만드는 것을 목표로 합니다.

## 2. Business Context

### Problem Statement
인쇄 비용은 교육 소외 계층에게 실질적인 학습 장벽입니다. 잉크 카트리지와 용지 비용 부담으로 인해 학습 자료를 충분히 출력하지 못하는 가정과 지역사회가 존재하며, 이는 경제적 불평등이 교육 격차로 이어지는 구조적 문제입니다. 기존 에코폰트는 이 문제를 해결할 잠재력이 있으나, 알파벳 등 일부 언어에만 국한되어 한국어·아랍어·한자 등 다양한 언어권 사용자는 혜택을 받지 못합니다. 또한 단순한 구멍 뚫기 방식은 언어별 획의 특성을 고려하지 못해 가독성이 저하되는 문제가 있습니다.

### Business Drivers
* **지속 가능한 소비와 생산 (SDG 12)**: 불필요한 잉크 사용 및 카트리지 폐기물 감소.
* **불평등 감소 (SDG 10)**: 높은 인쇄 비용으로 학습 자료 출력이 어려운 경제적 취약 계층에게 동일한 인쇄 기반 교육 기회 제공.
* **양질의 교육 (SDG 4)**: 교육청, 출판사, NGO 등 교육 자료를 대량 인쇄하는 기관이 운영 비용을 절감하여 더 많은 학습 자료를 더 많은 학습자에게 제공할 수 있는 환경 조성.

### Target Users and Stakeholders

| User Type | Description | Primary Need |
|-----------|-------------|--------------|
| **교육 소외 계층** | 인쇄 비용 부담으로 학습 자료 출력이 어려운 개인 및 가정 | 인쇄 비용 절감을 통한 학습 자료 접근성 향상 |
| **교육·출판 기관 담당자** | 교육청, 출판사, NGO 등 교육 자료를 대량 인쇄하는 기관 | 운영 비용 절감으로 더 많은 학습자에게 자료 제공 |
| **소수 언어 공동체** | 한국어·아랍어·한자 등 비라틴 계열 언어 사용자 | 자신의 언어로도 인쇄 비용을 절감할 수 있는 에코폰트 사용 |

### Business Constraints
* **기술 스택 요건**: Google Cloud 기술을 최소 1개 이상 사용하여 설계해야 함. 구체적인 인프라 구성은 tech_stack.md 참조.
* **파일 업로드 제한**: 단일 .ttf 파일 최대 용량은 10MB로 제한.
* **팀 및 예산 제약**: 대학생 4인으로 구성된 팀으로, 유료 서비스 및 인프라 비용 최소화가 최우선. 무료 티어 및 오픈소스 솔루션을 적극 활용해야 함.
* **릴리즈 일정**: MVP 단계로 1달 이내 릴리즈를 목표로 하며, 구현 범위는 핵심 기능에 집중하여 일정 내 완료 가능한 수준으로 제한.

### Success Metrics

| Metric | Current State | Target State | Measurement Method |
|--------|--------------|--------------|-------------------|
| 잉크 절약률 | 0% (표준 폰트 기준) | 평균 20% 이상 | 사용자가 업로드한 원본 폰트 대비, 300 DPI 고정 해상도 기준 벡터 면적 비교 |
| 가독성 유지율 | 100% (원본 기준) | OCR 인식률 95% 이상 | 변환 전후 OCR 정확도 비교 테스트 |

## 3. Full Scope Vision

### Product Vision Statement
세상의 모든 언어와 서체가 잉크 다이어트를 통해 지속 가능성을 입고, 누구나 자신의 언어적 정체성을 유지하며 환경 보호에 기여하는 '유니버설 에코 타이포그래피' 환경 구축.

### Feature Areas

#### Feature Area 1: 가독성-잉크절약 최적화 엔진
-   **Description**: 손실 함수(Loss Function) 기반의 폰트 구조 최적화 시스템.
-   **Key Capabilities**:
    -   구조적 유사도(SSIM)를 기반으로 가독성 훼손 최소화.
    -   잉크 사용량(벡터 면적) 최대 절감을 위한 손실 함수 최소화 파라미터 도출.
-   **User Value**: 시각적 불편함 없이 비용 절감과 환경 보호 동시 달성.

#### Feature Area 2: RAG 기반 스타일 전이 보강 *(Post-MVP)*
-   **Description**: Vertex AI(Gemini)와 Vector DB를 활용한 폰트 특징 검색 및 생성.
-   **Key Capabilities**:
    -   소수 언어의 부족한 폰트 특징을 유사 데이터셋에서 실시간 검색(Retrieve). 초기 데이터셋은 Google Fonts 등 오픈소스 폰트에서 글리프 임베딩을 추출해 Pinecone에 적재.
    -   검색된 특징을 바탕으로 자연스러운 에코폰트 외곽선 생성(Generation).
-   **User Value**: 데이터가 부족한 언어도 정교한 고품질 에코폰트로 변환 가능.

#### Feature Area 3: 인터랙티브 환경 대시보드
-   **Description**: 실시간 시각화 및 데이터 분석 대시보드.
-   **Key Capabilities**:
    -   폰트 변환 시 예상 잉크 절약률 및 탄소 저감량 실시간 표시. 탄소 저감량 = 절약된 잉크량(ml) × CO2 환산 계수(g/ml). **[TODO: 환산 계수 논문/보고서 근거 보강 필요]**
    -   브라우저 기반 실시간 폰트 렌더링 미리보기 제공.
-   **User Value**: 사용자의 행동이 환경에 미치는 긍정적 영향을 데이터로 체감.

## 4. MVP Scope

### MVP Objective
사용자가 업로드한 .ttf 파일을 핵심 최적화 알고리즘을 통해 에코폰트로 변환하고, 그 결과를 미리보기·절약률 데이터로 검증하며 변환된 파일을 다운로드하는 기능 구현.

### MVP Success Criteria
- [ ] 단일 .ttf 파일 업로드 및 에코폰트 변환 성공.
- [ ] 브라우저 상에서 원본과 변환 폰트의 가독성 비교 미리보기 렌더링.
- [ ] 변환된 에코폰트 .ttf 파일 다운로드 성공.

### Features In Scope (MVP)
| Feature | Description | Priority | Rationale for Inclusion |
|---------|-------------|----------|------------------------|
| .ttf 파일 업로드 | 사용자가 .ttf 파일을 웹에서 업로드하는 인터페이스 | Must Have | 서비스 진입점 |
| 가독성-잉크절약 최적화 엔진 | SSIM 기반 가독성 유지 + 손실 함수 최소화로 잉크 사용량 절감 | Must Have | 서비스의 핵심 알고리즘 |
| 원본/변환 비교 미리보기 | 브라우저에서 원본과 변환 폰트를 나란히 렌더링 | Must Have | 사용자 신뢰성 확보 및 가독성 검증 |
| 잉크 절약률 대시보드 | 변환 결과의 잉크 절약률(%) 및 탄소 저감량 시각화 | Must Have | 교육 기관·사용자의 환경적 기여도 증명 |
| 변환된 폰트 다운로드 | 변환 완료 후 에코폰트 .ttf 파일 다운로드 제공 | Must Have | 사용자가 결과물을 실제로 사용할 수 있어야 서비스 가치 완성 |

### Features Explicitly Out of Scope (MVP)
| Feature | Reason for Deferral | Target Phase |
|---------|-------------------|--------------|
| 가변 두께 조절 슬라이더 | 구현 난이도가 높으며 핵심 로직 검증 후 추가 가능 | Phase 2 |
| RAG 기반 스타일 전이 — 방법 1 (유사 폰트 검색으로 타공 파라미터 도출) · 방법 2 (소수 민족 언어 스타일 전이) | [일반 폰트-에코 폰트] 페어 데이터셋 선행 필요 및 MVP 기간 내 학습 완결 불가. 에코폰트 엔진 안정화 후 축적된 변환 데이터로 도입 예정 | Post-MVP |
| 사용자별 누적 절감 통계 | 로그인 기능 및 영구 DB 연동 필요 | Phase 2 |

## 5. Risks and Dependencies

### Key Risks
| Risk | Likelihood | Impact | Mitigation |
|------|-----------|--------|------------|
| 폰트 저작권 침해 우려 | High | High | 서비스 약관에 '개인 확인용' 명시. GCS Lifecycle 1일 자동 삭제 정책으로 원본 파일 보관 최소화 |
| 복잡한 문자(한자 등) 가독성 저하 | Medium | High | 획이 복잡한 경우 펀칭 강도를 자동 조절하는 알고리즘 보완 |
| 인프라 비용 발생 | Low | Medium | GCS 및 Cloud Run의 무료 티어 활용 및 최적화 |

### External Dependencies
-   **Google Cloud Platform**: Cloud Run (백엔드), GCS (파일 스토리지) 활용.
-   **Vercel**: Next.js 프론트엔드 호스팅.
