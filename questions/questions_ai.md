## Q1. RAG 초기 폰트 데이터셋 구축

RAG는 Pinecone에 폰트 글리프 임베딩이 사전에 채워져 있어야 동작함. MVP에서 이 데이터셋을 어떻게 확보할지 미정.

A) 공개 폰트 데이터셋 활용 — Google Fonts 등 오픈소스 폰트에서 글리프 임베딩을 직접 추출해 Pinecone에 적재
B) 소량 직접 수집 — 팀이 직접 선별한 소수 폰트로 최소 데이터셋 구축 후 점진적 확장
C) MVP에서 RAG 제외 — 최적화 엔진만으로 MVP 구현, RAG는 Phase 2로 이동

[Answer]:A

## Q2. 탄소 저감량 계산 기준

대시보드에서 탄소 저감량 표시 예정이나 계산 공식 미정.

A) 잉크 절약량 기반 CO2 환산 — 업계 표준 수치(예: 잉크 1ml = CO2 Xg) 적용
B) 탄소 저감량 표시 제거 — 잉크 절약률(%)과 절약된 잉크량(ml)만 표시
C) 근사 추정값 표시 — 참고 논문/보고서 기반 근사 수치 사용, 면책 문구 병기

[Answer]:A
