# Business Overview

```

+------------------+   에코폰트 TTF 다운로드  +---------------------+
                                                      |

                   |  AI 최적화 엔진  |       |  가독성 검증     |
                   | (SSIM 기반)     |       | (OCR 파이프라인) |
                   +-----------------+       +-----------------+
```

## Business Description

- **Business Description**: 사용자가 업로드한 TTF 폰트 파일을 AI 기술로 잉크 절약형 에코폰트로 자동 변환하는 웹 플랫폼. 가독성을 유지하면서 잉크 사용량을 최소 20% 절감하는 것을 목표로 함.
- **Business Transactions**:
  1. **폰트 업로드**: 사용자가 TTF 파일을 업로드 (드래그앤드롭 또는 파일 선택)
  2. **에코폰트 변환**: AI 최적화 엔진이 글리프 벡터를 분석하여 잉크 절약형 구조로 변환
  3. **가독성 검증**: OCR 파이프라인으로 변환 전후 인식률 비교 (95% 기준)
  4. **결과 확인**: 잉크 절약률, 탄소 저감량, 원본/변환 폰트 미리보기 제공
  5. **다운로드**: 변환된 에코폰트 TTF 파일 다운로드
- **Business Dictionary**:
  - **에코폰트**: 잉크 사용량을 줄이도록 최적화된 폰트
  - **잉크 절약률**: 원본 대비 절감된 잉크 면적 비율 (300 DPI 기준 벡터 면적 비교)
  - **탄소 저감량**: 절약된 잉크량 x CO2 환산 계수
  - **OCR 인식률**: 변환 전후 OCR 정확도 비교 지표 (목표: 95% 이상 유지)
  - **SSIM**: 구조적 유사도 지수 (최적화 손실 함수에 활용)
  - **글리프**: 폰트를 구성하는 개별 문자 형태

## Component Level Business Descriptions

### Frontend (apps/frontend)
- **Purpose**: 사용자가 TTF 파일을 업로드하고, 변환 결과를 확인하며, 에코폰트를 다운로드하는 웹 인터페이스 제공
- **Responsibilities**: 파일 업로드 UI, 변환 진행 로딩 표시, 잉크 절약률/탄소 저감량 대시보드, 원본/변환 폰트 비교 미리보기, 변환 파일 다운로드

### Backend / Font Processing (미구현)
- **Purpose**: TTF 파일 파싱, 잉크 절약률/탄소 저감량 계산, GCS 연동
- **Responsibilities**: FastAPI 서버, FontTools 기반 글리프 벡터 추출, 계산 로직

### AI 최적화 엔진 (미구현)
- **Purpose**: SSIM 기반 손실 함수로 글리프 구조를 최적화하여 잉크 절약형 에코폰트 생성
- **Responsibilities**: 에코폰트 외곽선 생성, 전체 AI 파이프라인 통합

### OCR 가독성 검증 파이프라인 (미구현)
- **Purpose**: 변환 전후 OCR 정확도를 비교하여 가독성 기준(95%) 충족 여부 검증
- **Responsibilities**: OCR 모델 운영, 소수 민족 언어 범위 지원, 검증 결과 반환
